# Vehicle Damage Classification Using Deep Learning

**Student:** Anjali Tummala  
**Course:** COMP-671 Deep Learning  
**University:** Rivier University

## Project Overview

This project explores how deep learning can classify vehicle damage from images. It compares a basic convolutional neural network (CNN) with a transfer-learning approach using ResNet50.

## Research Questions

1. Can transfer learning improve vehicle damage classification compared with a basic CNN?
2. Does image data augmentation improve model generalization?

## Planned Methods

- Explore and preprocess a labeled vehicle-damage image dataset.
- Train and evaluate a baseline CNN.
- Train and evaluate ResNet50 using transfer learning.
- Compare ResNet50 with and without data augmentation.
- Evaluate classification performance and investigate incorrect predictions.

## Evaluation Metrics

Accuracy, precision, recall, F1-score, confusion matrix, and training/validation curves.
